# HiveEngineExplorer

Explorer for the Hive-Engine sidechain.

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run dev
```

### Compiles and minifies for production
```
npm run build
```

### Preview the production build locally
```
npm run preview
```

### Lints and fixes files
```
npm run lint
```

## Stack

- Vue 3 (Composition API, `<script setup>`)
- Vite
- vue-router
- Nuxt UI (Vue) + Tailwind CSS
